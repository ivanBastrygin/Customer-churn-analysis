# Customer Churn: анализ оттока клиентов банка

**Цель:** определить, с какими характеристиками клиентов связан уход из банка, выделить наиболее рискованные сегменты и оценить, какие направления удержания стоит исследовать подробнее.

**Данные:** 10 000 клиентов из Франции, Германии и Испании. Целевая переменная `Exited`: `1` — клиент ушёл, `0` — остался. Доля оттока в выборке — **20,4%**.

**Стек:** Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn, statsmodels.

## Данные и методология

В датасете 14 столбцов: кредитный рейтинг, страна, пол, возраст, стаж обслуживания, баланс, количество банковских продуктов, наличие кредитной карты, активность клиента, оценочная зарплата и целевая переменная `Exited`, а также идентификаторы.

Перед анализом выполнены проверки качества данных: пропуски, полные дубликаты, повторяющиеся `CustomerId` и логические аномалии. Идентификаторы исключены из анализа как признаки без самостоятельной поведенческой информации.

Далее доля оттока сравнивалась по возрасту, стране, полу, числу продуктов, активности и финансовым характеристикам. Для групп рассчитывались размеры выборок и 95%-е доверительные интервалы Уилсона.

Связь признаков с оттоком дополнительно оценивалась через размер эффекта и взаимную информацию. Для взаимной информации использовался шумовой порог, полученный перестановкой целевой переменной. Отдельно исследовались пересечения признаков и вклад рискованных сегментов в общий отток и суммарный баланс.

## Главные результаты

### Отток по ключевым сегментам

| Сегмент | Результат |
|---|---:|
| Общий отток | **20,4%** |
| Клиенты 41–60 лет | 31% базы и 61% всех ушедших |
| Германия | **32,4%** оттока |
| Франция и Испания | 16–17% оттока |
| Неактивные клиенты | **26,9%** оттока |
| Активные клиенты | 14,3% оттока |

### Наиболее рискованный сегмент

Самая заметная группа риска — **неактивные клиенты 41–60 лет**:

- 16% всей клиентской базы;
- 39% всех ушедших клиентов;
- уровень оттока внутри сегмента — **51%**.

Это направление выглядит приоритетным для дальнейшей проверки гипотез удержания.

### Влияние на клиентскую базу и баланс

Ушедшие клиенты представляли **24,3% суммарного баланса**. На клиентов из Германии приходилось 12,8% суммарного баланса всей базы.

Кредитный рейтинг, оценочная зарплата, стаж обслуживания и наличие кредитной карты не показали содержательной связи с оттоком в рамках проведённого анализа.

### Ограничения интерпретации

У клиентов с тремя и четырьмя продуктами наблюдался очень высокий отток — 83% и 100%. Однако эти значения основаны на малых группах. Их нельзя напрямую превращать в продуктовые решения без дополнительной проверки данных.

## Итог

Отток распределён по клиентской базе неравномерно. Наиболее выраженные различия связаны с возрастом, страной и активностью клиента. В первую очередь стоит изучить удержание неактивных клиентов 41–60 лет, а также отдельно разобраться с высоким уровнем оттока в Германии.

Результаты описывают связи в наблюдательных данных и **не доказывают причинность**. Для выбора конкретных мер удержания потребуются дополнительные проверки и экспериментальная оценка их эффективности.
